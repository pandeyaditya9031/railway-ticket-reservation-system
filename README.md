A web-based **Railway Ticket Reservation System** developed using **Python, Flask, SQLite, HTML, CSS, and JavaScript**. This project allows users to view train details, reserve tickets, cancel reservations, update train information, and check ticket status through a simple and user-friendly interface.

---

# 📖 Project Overview

The Railway Ticket Reservation System is designed to simplify the railway ticket booking process. It demonstrates CRUD (Create, Read, Update, Delete) operations using Flask with SQLite database integration.

---

# ✨ Features

- 🚆 View Train Details
- 🎫 Reserve Train Tickets
- ❌ Cancel Tickets
- ✏️ Update Train Details
- 🔍 Check Ticket Status
- 💾 SQLite Database Integration
- 🌐 User-Friendly Web Interface

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

## Move into Project Folder

```bash
cd train-reservation
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Run Project

```bash
python app.py
```

Open your browser:

```
http://127.0.0.1:5000
```
